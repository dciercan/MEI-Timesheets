# **App Name**: TempoTrack

## Core Features:

- Timesheet Entry: Enable Crew Supervisors to input timesheet data for their crew members, including date, location, activity, productive hours, quantity, and optional unproductive time. Use a tool to populate fields in Activity selection using LLM to prevent incorrect data input. 
- Crew Member Selection: Allow Crew Supervisors to select crew members from a predefined list of users.
- Location Selection: Capture timesheet location details, Zone and Section.
- Activity and Hours Input: Input productive hours and quantity for the selected activity, with corresponding unit of measure.
- Unproductive Time Input: Optional input for unproductive time with reason and hours.
- Timesheet Notes: Allow supervisors to add notes.
- Timesheet Admin View: Allow admins to view all timesheet entries.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a sense of trust and reliability.
- Background color: Light blue (#E8EAF6), a desaturated tint of the primary color.
- Accent color: Teal (#009688) to give important information a different highlight. 
- Font pairing: 'Inter' for headlines and 'PT Sans' for body text. Inter is a sans-serif, PT Sans is also a sans-serif.
- Simple, clear icons representing actions like submitting or approving timesheets.
- Responsive design for mobile and desktop viewing.
- Subtle transitions when navigating between timesheet entries and sections.
